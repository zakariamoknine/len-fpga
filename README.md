# len-fpga

len-fpga is an FPGA-based SoC platform, designed primarly to run the *len* kernel

> [!WARNING]
>
> This project as-in is only meant to be ran on an Nexys A7-100T FPGA. Many elements are hardcoded only for this FPGA.
